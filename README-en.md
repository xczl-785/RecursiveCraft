# RecursiveCraft

[简体中文](./README.md) | English

RecursiveCraft is a Minecraft mod that helps players perform recursive crafting using the materials already in their inventory.

## Public Support

- Minecraft: `1.20.1`
- Loaders: `Forge`, `Fabric`

## Features

- Builds a crafting path for a target item from known recipes
- Executes recursive crafting from the player's current inventory
- Provides both block mode and handheld mode
- Works with JEI-triggered crafting flows
