# RecursiveCraft

[English](./README-en.md) | 简体中文

RecursiveCraft 是一个 Minecraft 递归合成辅助 Mod，目标是让玩家基于当前背包中的材料，自动完成递归合成。

## 当前公开支持

- Minecraft: `1.20.1`
- Loaders: `Forge`、`Fabric`

## 功能概览

- 基于已知配方为目标物品规划递归合成路径
- 根据玩家当前背包材料执行递归合成
- 提供方块模式与手持模式
- 支持 JEI 触发的递归合成流程
